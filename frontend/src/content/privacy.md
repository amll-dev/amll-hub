# AMLL Hub 隐私政策

生效日期：<u>2026年10月4日</u>

版本：v1.0

欢迎使用 AMLL Hub（以下简称「本平台」）。我们深知个人信息对您的重要性，并将按照法律法规要求，采取相应的安全保护措施，尽力保护您的个人信息安全可控。

本隐私政策旨在向您说明：当您使用本平台（包括 [https://beta.amllhub.bikonoo.com](https://beta.amllhub.bikonoo.com) 及其相关服务）时，我们如何收集、使用、存储和共享您的个人信息，以及您如何行使相关权利。**在使用本平台前，请您仔细阅读并充分理解本政策。您使用本平台即表示您同意本政策所述内容。**

本隐私政策与[《AMLL Hub 用户协议》](/terms)共同构成您与本平台之间的完整约定。如本政策与用户协议存在不一致，以本政策为准。

## 一、适用范围

本政策适用于您通过本平台网站、接口及小程序（如有）等方式使用本平台各项功能时对您个人信息的处理。

请您注意，本平台部分功能（在线搜索、歌词解析、网易云/QQ/酷狗音乐接口调用等）依赖第三方服务，您在第三方平台上的信息处理行为适用该第三方平台的隐私政策，本平台不承担超出法律规定范围的责任。

## 二、我们收集的信息

我们仅收集为提供服务所必需的信息，主要包括以下几类：

### （一）您主动提供的信息

1. **注册与账号信息**：您注册账号时提供并维护的用户名、密码、邮箱、手机号、昵称等信息。其中，密码由本平台自建并部署的身份认证服务（Casdoor）加密存储（Casdoor 由运营方自行部署，账号数据存储于运营方控制的服务器）；本平台自身的业务数据库中不保存用户账号密码。
2. **个人资料**：您在个人中心设置的头像、昵称；您修改绑定的邮箱、手机号时提交的验证码信息。
3. **投稿内容**：
   - 歌词投稿：您上传的歌词文件（TTML 格式，包含歌曲标题、艺术家、专辑、各平台音乐 ID、歌词文本、翻译、音译及歌词制作者等元数据）、备注、标签、语言信息；
   - 音频与封面：您为辅助审核与试听上传的音频文件、封面图片；
   - 搜索 IP 投稿：您投稿的偶像团体/成员资料（名称、别名、颜色、图片等）；
   - 每日推荐投稿：您投稿推荐的歌曲信息（歌名、艺术家、封面、推荐语等）；
   - 评论内容。
4. **联系与反馈信息**：您联系我们时提供的联系方式及反馈内容。

### （二）我们自动收集的信息

1. **日志信息**：当您访问本平台时，我们会自动记录您的 IP 地址、User-Agent（浏览器/设备标识）、访问路径、请求参数、状态码、响应时间等信息，用于保障服务安全、排查故障、防止滥用。
2. **无歌词记录信息**：当您查询的歌曲不存在歌词时，我们会记录该歌曲的平台 ID、歌曲名、歌手等信息，并可能记录**首次查询该记录的 IP 地址**，用于去重统计与防滥用（仅保存于服务器端，不会在排行榜中公开展示 IP）。
3. **点赞与活动记录**：您的每日推荐点赞记录（关联您的用户名）、投稿与审核活动的统计数据（用于个人贡献墙展示）。

### （三）本地存储信息

为提升使用体验，本平台会在您的浏览器本地存储（localStorage）中保存登录令牌（JWT Token）及已登录用户的基本资料缓存（键名为 `amll_hub_token`、`amll_hub_user`），用于维持登录状态。您退出登录或清除浏览器数据即可删除上述信息。

## 三、我们如何使用信息

我们收集的信息将用于以下目的：

1. 为您提供账号注册、登录、身份验证、密码找回、资料修改等服务；
2. 为您提供歌词检索、在线搜索、歌词解析、批量查询等服务；
3. 处理您的歌词、每日推荐、搜索 IP 投稿，并交由审核员进行人工审核；
4. 通过站内消息及电子邮件（如已启用邮件服务）向您通知投稿审核结果、评论提醒、系统公告等；
5. 为您展示个人活动统计（贡献墙）、每日推荐点赞等服务；
6. 用于无歌词记录统计、词库排行榜与词库运营分析；
7. 保障服务安全与稳定，包括身份认证、风控、防滥用、故障排查、日志审计；
8. 改进产品与服务质量，研发新功能；
9. 履行法律法规规定的义务，或在法律允许的范围内维护您及第三方的合法权益。

## 四、Cookie 与本地存储

本平台使用浏览器本地存储（localStorage）保存登录状态，**不使用**用于广告追踪的第三方 Cookie。您可以在浏览器设置中清除本地存储数据；但请注意，清除后您需要重新登录。

## 五、信息的共享、委托处理与第三方

我们不会向任何无关第三方出售、出租或共享您的个人信息。我们仅在以下情形中处理、共享或委托处理您的信息：

1. **委托处理（自建基础设施）**：本平台的身份认证组件（Casdoor）以及 PostgreSQL、Redis、MinIO 对象存储、MeiliSearch、RabbitMQ 等基础设施组件均由运营方自行部署，您的账号数据与业务数据存储于运营方控制的服务器上。该等组件仅受运营方委托处理数据，**不属于向第三方共享个人信息**。
2. **在获得您明确同意的前提下共享**；
3. **为提供服务所必需，向服务所依赖的第三方共享**，具体如下：

| 第三方                                    | 用途                                             | 涉及的您的信息                                                                         |
| ----------------------------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------- |
| GitHub（amll-ttml-db 仓库）               | 歌词库数据同步；投稿通过审核后收录并公开歌词文件 | 投稿歌词文件及其元数据、投稿人的公开资料（如投稿时关联的 GitHub 信息，如有）           |
| 网易云音乐 / QQ 音乐 / 酷狗音乐等平台接口 | 在线歌曲搜索、歌词获取、歌单解析、无歌词歌曲分类 | 您提交的搜索关键词、歌曲/歌单 ID（不含账号密码等敏感信息）                             |
| 阿里云人机验证服务                        | 注册、登录、发送验证码等场景的人机校验           | 人机验证所需的设备环境信息（由阿里云处理，详见阿里云验证码隐私说明）                   |
| 邮件服务（SMTP，可选启用）                | 向您发送审核结果等通知邮件                       | 您的邮箱地址、用户名、投稿标题等信息（如使用第三方邮件服务，则适用该服务商的隐私政策） |

4. **在法律法规要求、行政机关或司法机关依法要求的情况下**，我们可能对外提供您的个人信息；
5. 当本平台发生合并、收购、资产转让等情形时，我们可能将您的个人信息转移给承继方，并会要求承继方继续遵守本政策。

需要特别说明的是：

- **公开内容**：您的昵称、头像以及通过审核的投稿信息（歌词文件、投稿标题、艺术家等）将在本平台及歌词库中公开展示，任何访问者均可查看。请您在提交前确认相关内容不包含您不愿公开的个人信息。
- **歌词库共享**：您投稿并通过审核的歌词内容将按歌词库的共享协议（投稿者编写部分为 CC0 1.0，外来数据部分遵循原平台共享协议）公开共享，具体请参阅[歌词库说明](https://github.com/amll-dev/amll-ttml-db)。
- **跨境传输**：您投稿并通过审核的歌词文件将被上传至 GitHub 的 amll-ttml-db 仓库（GitHub 服务器位于境外），歌词库的同步与公开亦涉及与 GitHub 的数据交互，即您的投稿内容将传输至境外服务器存储并公开展示。我们将依照法律法规对相关处理进行合规评估，并采取必要措施保障您的信息安全。
- **敏感个人信息**：本平台原则上不收集身份证号码、金融账户信息、精确行踪轨迹等敏感个人信息。请您在投稿、评论时亦避免填写此类信息。
- **自动化决策**：除用于安全风控的基础规则外，本平台不对您进行影响您重大权益的自动化决策或用户画像。

## 六、信息的存储与安全

1. **存储位置与期限**：您的个人信息存储于我们自建或委托的服务器（含身份认证组件 Casdoor 以及 PostgreSQL、Redis、MinIO 对象存储、MeiliSearch、RabbitMQ 等组件）中，用于保障服务运行。具体保留期限见第七条。
2. **安全措施**：我们采用传输加密（HTTPS）、访问控制、身份认证、日志审计、数据备份等技术和管理措施保护您的个人信息。同时，我们对投稿审核、账号操作等敏感环节设置了人机验证、验证码、失败锁定等安全机制。
3. 尽管我们已采取合理措施，但请您理解，任何网络环境下的数据传输与存储都无法保证绝对安全。如发生个人信息安全事件，我们将按照法律法规的要求及时告知您并采取补救措施。
4. 您的登录令牌由您保管。请勿向他人泄露您的密码、验证码，并在公共设备上使用后及时退出登录。

## 七、信息的保留

我们仅在实现本政策所述目的所必需的期限内保留您的个人信息，具体如下：

1. **账号信息**：在您的账号存续期间保留。您可随时在个人中心修改昵称、头像、邮箱、手机号等资料。
2. **投稿信息**：在投稿存续期间保留，用于审核、追溯与歌词库维护；通过审核并收录进歌词库的歌词文件按歌词库规则长期保留。
3. **站内消息**：系统会定期清理超过 90 天的历史站内消息。
4. **无歌词记录**：未收录歌曲的无歌词记录每周清空一次；被识别为「纯音乐」「云盘音乐」并加入白名单的记录会永久保留，用于避免重复查询。
5. **日志信息**：请求日志保留有限期限，用于安全审计与故障排查。
6. 法律法规另有规定或行政、司法机关另有要求的，从其规定。

## 八、未成年人保护

本平台面向音乐与歌词爱好者提供服务。若您为未成年人，请在监护人指导下使用本平台，并在征得监护人同意后提交个人信息。若我们发现在未取得监护人同意的情况下收集了未成年人的个人信息，将尽快删除相关内容。

## 九、您的权利

依照相关法律法规，您对您的个人信息享有以下权利：

1. **访问与更正**：您可以在个人中心查看、修改您的昵称、头像、邮箱、手机号、密码等账号资料；
2. **撤回同意**：您可以在浏览器设置中清除本地存储的登录状态；如您的账号与第三方平台（如 GitHub）存在关联授权，您可自行在对应平台解除授权；
3. **删除与注销**：您可以通过本政策第十一条的联系方式向我们申请删除特定个人信息或注销账号。我们会在核实您的身份后依法处理。请注意，依据歌词库的共享协议，已经公开放入歌词库并由第三方使用的歌词内容可能无法完全删除，相关删除请求将依据法律法规及协议约定处理；
4. **投诉举报**：您有权就我们处理个人信息的行为向有关监督管理部门投诉、举报。
