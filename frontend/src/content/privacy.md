# AMLL Hub 隐私政策

生效日期：2026年11月15日

版本：v2.0

欢迎使用 AMLL Hub（以下简称「本平台」）。我们深知个人信息对您的重要性，并将按照法律法规要求，采取相应的安全保护措施，尽力保护您的个人信息安全可控。

本隐私政策旨在向您说明：当您使用本平台网站（[https://beta.amllhub.bikonoo.com](https://beta.amllhub.bikonoo.com) 及其网页端相关接口）时，我们如何收集、使用、存储和共享您的个人信息，以及您如何行使相关权利。**在使用本平台前，请您仔细阅读并充分理解本政策。您使用本平台即表示您同意本政策所述内容。**

本隐私政策与[《AMLL Hub 用户协议》](/terms)共同构成您与本平台之间的完整约定。如本政策与用户协议存在不一致，以本政策为准。

## 一、适用范围

本政策适用于您通过本平台网站（含网页端调用的接口）使用歌词检索、在线搜索、投稿审核、歌词请愿、插件商店、用户主页、文档中心、消息中心等功能时对您个人信息的处理。

本政策**不适用于**通过应用商店或其他渠道分发的独立客户端（包括但不限于 AMLL Hub Android 应用）。该等客户端对个人信息的处理不适用本政策，应以该客户端另行提供的隐私说明为准。

请您注意，本平台部分功能（在线搜索、歌词解析、音源播放、网易云/QQ/酷狗音乐接口调用等）依赖第三方服务，您在第三方平台上的信息处理行为适用该第三方平台的隐私政策，本平台不承担超出法律规定范围的责任。

## 二、我们收集的信息

我们仅收集为提供服务所必需的信息，主要包括以下几类：

### （一）您主动提供的信息

1. **账号与身份信息**：您注册账号时提供并维护的用户名、密码、邮箱、手机号、昵称等信息。其中，密码由本平台自建并部署的身份认证服务（Casdoor）加密存储（Casdoor 由运营方自行部署，账号数据存储于运营方控制的服务器）；本平台自身的业务数据库中不保存用户账号密码。
2. **GitHub 账号信息**：当您使用 GitHub 登录或绑定 GitHub 时，我们会获取并保存您的 GitHub 数字 ID、GitHub 用户名、GitHub 邮箱与头像。授权过程中获取的 GitHub 访问令牌仅用于读取上述资料，不会写入本平台业务数据库。您可在个人中心解除绑定。
3. **多因素认证（MFA）信息**：当您启用身份验证器应用、邮箱验证码或短信验证码等 MFA 因子时，相关因子状态与身份验证器密钥由 Casdoor 生成、存储与校验，恢复码由 Casdoor 生成并在启用时展示给您；接收验证码所需的邮箱或手机号来源于您的账号信息。
4. **个人资料**：您在个人中心设置的头像、昵称、个性签名、主页背景图；您可选择填写的生日、性别；您修改绑定的邮箱、手机号时提交的验证码信息。
5. **投稿与社区内容**：
   - **歌词投稿**：您上传的歌词文件（TTML 格式，包含歌曲标题、艺术家、专辑、各平台音乐 ID、歌词文本、翻译、音译、语言标签、歌词作者 GitHub ID 等元数据）、备注、标签、未重排原因；
   - **修正投稿**：您提交的修正版 TTML、目标歌曲/原歌词文件信息、差异快照与修订说明；
   - **音频与封面**：您为辅助审核与试听上传的音频文件、封面图片；
   - **歌词请愿**：您发起的请愿信息（歌曲名、艺术家、专辑、各平台音乐 ID、补充信息、备注）以及您的附议与评论记录；
   - **搜索 IP 投稿**：您投稿的偶像团体/成员资料（名称、别名、颜色、图片等）；
   - **每日推荐投稿**：您投稿推荐的歌曲信息（歌名、艺术家、封面、推荐语等）；
   - **插件投稿**：您提交的插件包（ZIP）、插件清单（manifest）、图标、简介、详细说明、README、更新日志、主页、仓库地址、许可证、标签、支持平台与最低客户端版本等资料；
   - **评论、评分与附议**：您在投稿、插件、请愿等页面发布的内容、评分与附议记录。
6. **联系与反馈信息**：您联系我们时提供的联系方式及反馈内容。

### （二）我们自动收集的信息

1. **日志信息**：当您访问本平台时，我们会自动记录您的 IP 地址、User-Agent（浏览器/设备标识）、访问路径、请求参数、状态码、响应时间、请求标识等信息，用于保障服务安全、排查故障、防止滥用与访问审计。
2. **无歌词记录信息**：当您查询的歌曲不存在歌词时，我们会记录该歌曲的平台 ID、歌曲名、歌手、专辑、封面等信息，并可能记录**首次查询该记录的 IP 地址以及按日去重统计的查询 IP 列表**，用于去重统计与防滥用。上述 IP 信息仅保存于服务器端，不会在排行榜中公开展示。
3. **互动与活动记录**：您的每日推荐点赞记录、歌词请愿附议记录、插件评分记录（均关联您的用户名）、投稿与审核活动的统计数据（用于个人主页与贡献墙展示）、审核、插件处置、文档编辑等管理操作记录（用于追溯与审计）、插件下载量等聚合统计。
4. **登录与会话辅助信息**：扫码登录时生成的一次性票据及其状态、确认登录的账号关联信息；MFA 二次验证会话、验证码发送冷却与失败次数等安全状态。上述信息通常仅在数分钟至数小时内有效。

### （三）本地存储信息

为提升使用体验，本平台会在您的浏览器本地存储（localStorage）中保存登录令牌（JWT Token）及已登录用户的基本资料缓存（键名为 `amll_hub_token`、`amll_hub_user`），用于维持登录状态。此外，浏览器本地可能保存主题偏好、编辑器设置、未提交的表单草稿、自定义编辑器背景图片等仅用于本地展示与恢复的内容，上述本地数据不会自动上传至服务器。您退出登录或清除浏览器数据即可删除上述信息。

## 三、我们如何使用信息

我们收集的信息将用于以下目的：

1. 为您提供账号注册、登录、身份验证、MFA、密码找回、资料修改、GitHub 绑定与解绑、扫码登录等服务；
2. 为您提供歌词检索、在线搜索、歌词解析、音源播放、批量查询等服务；
3. 处理您的歌词投稿、修正投稿、每日推荐、搜索 IP 投稿与插件投稿，并交由审核员或管理员进行人工审核；
4. 维护歌词历史版本、歌词请愿及请愿完成状态、用户主页与贡献统计；
5. 运营插件商店，包括插件展示、版本分发、下载统计、评分、评论、审核、上架与下架处置；
6. 提供文档中心的歌词库与 API 文档浏览服务；
7. 通过站内消息及电子邮件（如已启用邮件服务）向您通知投稿审核结果、插件审核结果、评论提醒、系统公告等；
8. 在您主动发起且已绑定 GitHub 的前提下，执行投稿数据迁移，将您在歌词库仓库中的历史 PR 转换为站内投稿记录；
9. 保障服务安全与稳定，包括身份认证、风控、防滥用、限流、故障排查、日志审计；
10. 改进产品与服务质量，研发新功能（我们可能使用去标识化或聚合后的统计信息）；
11. 履行法律法规规定的义务，或在法律允许的范围内维护您及第三方的合法权益。

## 四、Cookie 与本地存储

本平台使用浏览器本地存储（localStorage）保存登录状态与本地偏好，**不使用**用于广告追踪的第三方 Cookie。本平台自身不接入广告或第三方用户画像服务。您可以在浏览器设置中清除本地存储数据；但请注意，清除后您需要重新登录，未提交的表单草稿与本地设置也会丢失。

人机验证等第三方组件可能为完成校验而处理必要的设备环境信息，具体适用该第三方的隐私说明。

- **自动化决策**：除用于安全风控的基础规则外，本平台不对您进行影响您重大权益的自动化决策或用户画像；投稿、插件及社区内容的处理以人工审核为主。

## 六、信息的存储与安全

1. **存储位置与期限**：您的个人信息存储于我们自建或委托的服务器（含身份认证组件 Casdoor 以及 PostgreSQL、Redis、MinIO 对象存储、MeiliSearch、RabbitMQ 等组件）中，用于保障服务运行。具体保留期限见第七条。
2. **安全措施**：我们采用传输加密（HTTPS）、访问控制、身份认证、日志审计、数据备份等技术和管理措施保护您的个人信息。同时，我们对投稿审核、插件审核、账号操作等敏感环节设置了人机验证、MFA、验证码、失败锁定、限流与插件包校验等安全机制。
3. 您的登录令牌由您保管。请勿向他人泄露您的密码、MFA 凭证、恢复码或验证码，并在公共设备上使用后及时退出登录。安装插件前请确认其来源与权限，避免插件访问您不愿共享的本地数据。
4. 尽管我们已采取合理措施，但请您理解，任何网络环境下的数据传输与存储都无法保证绝对安全。如发生个人信息安全事件，我们将按照法律法规的要求及时告知您并采取补救措施。

## 七、信息的保留

我们仅在实现本政策所述目的所必需的期限内保留您的个人信息，具体如下：

1. **账号信息**：在您的账号存续期间保留。您可随时在个人中心修改昵称、头像、邮箱、手机号、MFA 等资料。
2. **个人主页资料**：在您的账号存续期间保留，直至您修改、清空或申请注销账号。
3. **投稿信息**：在投稿存续期间保留，用于审核、追溯与歌词库维护；通过审核并收录进歌词库的歌词文件及历史版本按歌词库规则长期保留；未通过审核、已关闭的投稿及相关审核记录在必要的追溯与审计期限内保留。
4. **插件信息**：在插件上架期间保留；插件下架、撤回或删除后，为版本回滚、审计、争议处理与法律合规所必需的期限内仍可能保留插件包、审核记录与操作日志。
5. **歌词请愿与社区互动**：在请愿或相关内容存续期间保留；请愿完成、关闭或内容删除后，为追溯与审计所必需的期限内可能保留相关记录。
6. **站内消息**：系统会定期清理超过 90 天的历史站内消息。
7. **无歌词记录**：未收录歌曲的无歌词记录每周清空一次；被识别为「纯音乐」「云盘音乐」并加入白名单的记录会永久保留，用于避免重复查询。
8. **日志信息**：请求日志在实现安全审计、故障排查与防滥用所必需的期限内保留。
9. **登录与会话辅助信息**：扫码登录票据、验证码冷却、MFA 验证会话等在数分钟至数小时内失效并清理。
10. **迁移任务记录**：投稿数据迁移的任务状态、PR 编号与处理结果在必要的追溯与审计期限内保留。
11. 法律法规另有规定或行政、司法机关另有要求的，从其规定。

## 八、未成年人保护

本平台面向音乐与歌词爱好者提供服务。若您为未成年人，请在监护人指导下使用本平台，并在征得监护人同意后提交个人信息。若我们发现在未取得监护人同意的情况下收集了未成年人的个人信息，将尽快删除相关内容。

## 九、您的权利

依照相关法律法规，您对您的个人信息享有以下权利：

1. **访问与更正**：您可以在个人中心查看、修改您的昵称、头像、邮箱、手机号、密码、个性签名、主页背景图、生日、性别等资料；可以查看自己的投稿、请愿、评论与插件信息，并管理自己的投稿与插件。
2. **撤回同意与解除授权**：您可以在浏览器设置中清除本地存储的登录状态；可以解除 GitHub 绑定；可以在安全设置中关闭已启用的 MFA 因子；可以撤回或删除自己发起的歌词请愿。
3. **删除与注销**：您可以通过本政策第十一条的联系方式向我们申请删除特定个人信息或注销账号。我们会在核实您的身份后依法处理。请注意，依据歌词库的共享协议，已经公开放入歌词库并由第三方使用的歌词内容可能无法完全删除；已上架的插件、公开评论等公开内容也可能因第三方已获取或共享协议持续有效而无法完全删除，相关删除请求将依据法律法规及协议约定处理。
