# AMLL Hub 用户协议

生效日期：2026年11月15日

版本：v2.0

欢迎使用 AMLL Hub（以下简称「本平台」）。本平台是一个为 AMLL 歌词生态提供逐词（TTML）歌词检索、在线搜索与解析、歌词投稿与审核、歌词请愿、歌词历史版本、插件商店、每日推荐、用户主页与文档中心等功能的歌词站点。

在使用本平台前，请您（以下简称「您」或「用户」）仔细阅读并充分理解本协议的全部内容。**当您注册、登录或以任何方式使用本平台的服务，即视为您已阅读、理解并同意接受本协议的全部条款。** 如您不同意本协议的任何内容，请停止注册或使用本平台。

如果您未满 18 周岁（或您所在司法辖区规定的成年年龄），请在监护人陪同下阅读本协议，并在取得监护人同意后使用本平台。

1. 本平台由 **AMLL-Dev**（以下简称「我们」）运营，服务网址为 **[https://beta.amllhub.bikonoo.com](https://beta.amllhub.bikonoo.com)**（当前为测试版本，正式地址以实际部署为准）。
2. 本平台代码基于开源项目 [amll-dev/amll-hub](https://github.com/amll-dev/amll-hub)，并按照 GNU AGPL-3.0 许可证开源。
3. 「歌词库」指 [amll-dev/amll-ttml-db](https://github.com/amll-dev/amll-ttml-db) 逐词歌词数据库及其镜像。
4. 「投稿」指您通过本平台提交的歌词文件（TTML 格式）、修正版本、音频文件、封面图片、备注、标签、差异快照及其他相关内容。
5. 「歌词请愿」指您通过本平台发起的求词请求，包括歌曲信息、备注、附议与评论等内容。
6. 「插件商店」指本平台提供的 AMLL 生态插件与主题的展示、分发与审核功能；「插件」指由第三方开发者制作并通过本平台分发、在 AMLL TTML Tool 等兼容的 AMLL 客户端或编辑器中运行的扩展程序或主题包。
7. 「审核员」指经本平台授权、负责对投稿、插件版本及其他社区内容进行人工审核的社区成员；「管理员」指经本平台授权、负责站点运营与管理的成员。
8. 「用户主页」指展示用户公开资料、投稿与贡献统计的公开页面；「文档中心」指本平台提供的歌词库与 API 使用文档。

## 二、服务内容

本平台向用户提供以下服务（具体以平台实际开放的功能为准）：

1. **歌词检索与获取**：按歌曲名、艺术家、专辑、歌词文本、拼音等方式搜索，并获取 TTML/LRC 等格式的歌词文件；
2. **批量查询与索引下载**：批量查询歌词、下载歌词库索引文件；
3. **在线搜索与解析**：通过网易云音乐、QQ 音乐、酷狗音乐等平台接口进行在线歌曲搜索、歌词获取、歌单解析与音源播放；
4. **无歌词记录与排行榜**：记录并公示暂未收录歌词的歌曲，帮助用户与社区了解词库缺口；
5. **歌词投稿与审核**：支持新歌词投稿、对已有歌词的修正投稿、在线歌词编辑器、未重排歌词模式、多语言标签及音频/封面附件；投稿经审核员审核后收录进歌词库；
6. **歌词历史版本**：查看同一歌词在歌词库中的历史版本，包括版本时间、平台映射、歌词作者等信息；
7. **歌词请愿**：发起求词请愿、附议支持、评论讨论，并在对应歌词收录后展示请愿完成状态；
8. **插件商店**：浏览、搜索、下载插件与主题，查看插件说明、版本与评论，对插件进行评分；符合条件的用户可以提交插件包、发布新版本、维护插件资料并下架自己的插件；审核员与管理员负责插件审核、上架与处置；
9. **每日推荐与搜索 IP**：投稿每日推荐歌曲、浏览每日推荐并点赞；投稿与浏览偶像团体/成员资料（搜索 IP）；
10. **用户主页与贡献统计**：展示用户公开资料、已通过审核的投稿以及投稿、审核等活动的统计信息；
11. **文档中心**：提供歌词库规范、投稿指南、API 使用说明等文档；
12. **消息中心与系统公告**：接收投稿审核结果、插件审核结果、评论提醒、系统公告等站内消息，并可通过已绑定邮箱接收通知邮件；
13. **账号与安全服务**：支持用户名密码登录、邮箱/手机验证码登录、GitHub 账号登录与绑定、多因素认证（MFA）、扫码登录，以及将绑定 GitHub 账号的历史投稿数据迁移至站内。

本平台部分功能（如歌词检索、获取、在线搜索、文档浏览）无需注册即可使用；投稿、请愿、评论、评分、插件发布、审核、消息中心、用户主页等社区功能需要注册并登录账号后方可使用。本平台当前为测试版本，部分功能可能调整、暂停或下线。

4. 本平台网页端支持扫码登录：网页端生成一次性登录票据并展示二维码，您需在已登录的 AMLL Hub 移动客户端中扫描并确认后完成登录。该票据具有有效期且仅可使用一次；请勿将二维码或票据分享给他人，也不要在非本人操作的情况下确认登录。

## 五、投稿、请愿与内容授权

1. **歌词投稿承诺。** 您投稿歌词时，应保证该歌词（包括逐词时间轴、翻译、音译等）系您本人制作，或您已获得权利人的合法授权；保证所填写的平台 ID 对应的音源与歌词一致；保证投稿内容不侵犯任何第三方的合法权益。原则上本平台主要接受音源来自网易云音乐、Apple Music、QQ 音乐、Spotify 的歌词投稿（具体以歌词库的审核细则为准）。
2. **修正投稿。** 您可以对歌词库中已有歌词提交修正投稿。您应保证所选目标歌曲与歌词文件正确，修正内容真实、必要且不侵犯第三方权益；修正投稿可能包含您提交的差异快照与修订说明。审核员也可能在上传修订版 TTML 后请您确认，您确认采用后该修订版将按审核结果处理。
3. **审核后公开。** 您理解并同意：您的投稿通过审核后，歌词文件（含歌曲标题、艺术家、专辑、平台 ID、歌词文本、翻译、音译、语言标签、歌词作者 GitHub ID 等元数据）将被收录并公开至 GitHub 的 amll-ttml-db 歌词库仓库及其镜像，向所有 AMLL 生态用户及公众开放检索与获取，并可能在歌词历史版本页面展示；未通过审核的投稿仅保留于本平台内部，供投稿人与审核员查看。
4. **音频与图片。** 您上传的音频文件、封面、图片等附件仅用于辅助审核、试听与展示。除法律另有规定或我们另行获得授权外，我们不会将这些附件用于歌词库收录以外的用途；您应保证上传的音频、图片不侵犯第三方权利。
5. **歌词请愿。** 您发起的歌词请愿（含歌曲信息、平台 ID、备注、附议与评论）将公开展示。您应保证请愿信息真实、准确，不重复发起同一请愿，不恶意附议或发布无关评论。本平台可能对重复请愿进行合并、关闭或调整状态，并可能在对应歌词收录后标记为已完成。
6. **每日推荐与搜索 IP。** 您提交的每日推荐（含歌曲信息、封面、推荐语）与搜索 IP 资料（含团体/成员资料、图片）将公开展示并接受审核。您应保证相关内容真实、合法且不侵犯第三方权利。
7. **用户主页资料。** 您在个人中心填写的个性签名、主页背景图，以及可选择填写的生日、性别，将展示在您的公开主页。上述信息均为自愿填写，请您谨慎决定是否公开；请勿在公开资料中填写身份证号、住址、财务信息等敏感个人信息。
8. **评论、评分与附议。** 您在投稿、插件、请愿等页面发布的评论、评分与附议记录将公开展示并关联您的用户名、昵称与头像。您应基于真实使用体验进行评价，不得发布违法、侵权、侮辱、广告或无关内容。本平台有权删除违规内容并视情节限制相关功能。
